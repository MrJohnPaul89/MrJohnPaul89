## Sobre mim

Sou **Joao Paulo Alves**, desenvolvedor web júnior e formado em **Análise e Desenvolvimento de Sistemas**.

Trabalho com desenvolvimento de aplicações web, interfaces responsivas e soluções digitais voltadas a necessidades reais de pequenos negócios.

Sou responsável pela **KYRAVEXIS**, uma iniciativa pessoal e autoral de software house, por meio da qual desenvolvo projetos independentes e soluções personalizadas.

Minha experiência prática envolve desenvolvimento web, implementação de funcionalidades, testes, versionamento de código e publicação de aplicações.

Busco uma oportunidade como **Desenvolvedor Web Júnior**, na qual possa contribuir com minha experiência prática e continuar evoluindo tecnicamente em equipe.

> Construindo, testando, corrigindo e evoluindo — um projeto de cada vez.

## Projetos em destaque

### Boi na Brasa — Site institucional

**Status:** Entregue e publicado

**Contexto:** Projeto comercial desenvolvido para uma hamburgueria artesanal de Piracaia/SP.

Desenvolvimento de site institucional responsivo, voltado à apresentação do estabelecimento, cardápio e canais de pedidos.

**Principais entregas:**

- Interface responsiva para dispositivos móveis e desktops.
- Apresentação de produtos e informações comerciais.
- Direcionamento para plataformas de pedidos online.
- Otimizações técnicas de SEO e desempenho.
- Melhorias de acessibilidade e experiência do usuário.
- Publicação e manutenção utilizando Cloudflare Pages.

### Do Prado — Sistema comercial de pedidos

**Status:** Em desenvolvimento

**Contexto:** Projeto real para comércio de carnes e charcutaria.

Desenvolvimento de uma solução web comercial para organização de pedidos, operações de venda e funcionalidades relacionadas à emissão de comandas.

**Escopo do projeto:**

- Interface de pedidos e catálogo de produtos.
- Carrinho de compras.
- Seleção de opções de preparação dos produtos.
- Organização do fluxo de pedidos.
- Funcionalidades voltadas à emissão de comandas.
- Integração com impressão comercial em desenvolvimento.

**Observação:** Projeto em andamento, com repositório privado. As funcionalidades de produção e impressão ainda estão sujeitas à conclusão e validação.
